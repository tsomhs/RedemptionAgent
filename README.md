# Redemptions agent

Κάθε μήνα πρέπει να μάθουμε από τους συνεργάτες ενός προγράμματος κουπονιών πόσα
κουπόνια εξαργυρώθηκαν. Ο agent το κάνει μόνος του: τους ρωτά με email, τους το
θυμίζει, διαβάζει τις απαντήσεις και δείχνει τα νούμερα σε ένα dashboard.

## Πώς δουλεύει

1. Παίρνει το αρχείο του μήνα, που λέει πόσα κουπόνια δόθηκαν σε κάθε προσφορά.
2. Στέλνει ένα email σε κάθε συνεργάτη και ρωτά πόσα εξαργυρώθηκαν.
3. Θυμίζει σε όσους δεν απάντησαν, έως τρεις φορές, μία την εβδομάδα.
4. Διαβάζει τις απαντήσεις. Όσες έχουν τον αριθμό δίπλα στο όνομα κάθε προσφοράς καταχωρούνται
   αμέσως· το ελεύθερο κείμενο και τα συνημμένα τα διαβάζει ένα μοντέλο AI.
5. Ό,τι δεν είναι σαφές το αφήνει σε άνθρωπο, στην καρτέλα «Προς έλεγχο». Ο agent
   δεν μαντεύει ποτέ αριθμό, και όποιος δεν απάντησε μένει κενός, όχι 0.
6. Δείχνει τα αποτελέσματα στο dashboard και τα δίνει σε Excel.

Τα δεδομένα μένουν σε δικό του αρχείο βάσης, στον φάκελο `data/`.

## Πώς το τρέχω

Χρειάζεται Python 3.11 ή νεότερη, σε Linux ή macOS.

```
make install
make run
```

Ανοίξτε το http://127.0.0.1:8765. Σταματά με Ctrl+C.

Την πρώτη φορά φτιάχνεται μια **δοκιμαστική βάση με επινοημένα δεδομένα**, ώστε
να υπάρχει κάτι να δείτε: οκτώ συνεργάτες που δεν υπάρχουν, έξι μήνες με νούμερα
και έναν μήνα σε εξέλιξη. Δεν χρειάζεται καμία ρύθμιση και κανένα email δεν
στέλνεται.

Αν το `make install` σταματήσει με μήνυμα για το `venv`, σε Ubuntu ή Debian
χρειάζεται πρώτα `sudo apt install python3-venv`.

Οι αυτόματοι έλεγχοι τρέχουν με `make test`.

## Το dashboard

- **Επισκόπηση** και **Αναλυτικά**: τα νούμερα ανά μήνα και ανά προσφορά, και η
  λήψη σε Excel.
- **Προς έλεγχο**: απαντήσεις που δεν ήταν σαφείς, emails που δεν παραδόθηκαν και
  emails που δεν ταιριάζουν σε κανένα αίτημα.
- **Αιτήματα**: κάθε αίτημα με την αλληλογραφία του.
- **Ρυθμίσεις**: τι κάνει ο agent μόνος του και πότε. Ο αυτοματισμός ξεκινά
  κλειστός.

## Με πραγματικά δεδομένα

Οι ρυθμίσεις είναι στο αρχείο `.env`, που το φτιάχνει το `make install`. Κάθε
γραμμή του έχει από πάνω την εξήγησή της.

1. Αλλάξτε το `AGENT_DB` σε `data/agent.db`, για να μη δουλεύετε στη δοκιμαστική
   βάση.
2. Συμπληρώστε το mailbox από το οποίο θα στέλνει και θα διαβάζει ο agent.
3. Αφήστε το αρχείο του μήνα στον φάκελο `input/`, με τον μήνα στο όνομά του,
   π.χ. `input/assignments_2026-11.xlsx`.
4. Φτιάξτε τη λίστα συνεργατών με `python main.py contacts-export
   docs/contacts.xlsx`, συμπληρώστε τα emails και φορτώστε τη με `python main.py
   contacts-import docs/contacts.xlsx`.
5. Προαιρετικά, βάλτε ένα κλειδί AI για να διαβάζεται και το ελεύθερο κείμενο.

Όσο το `MAIL_MODE` είναι `test`, ο agent στέλνει μόνο στις διευθύνσεις της λίστας
`ALLOWED_RECIPIENTS`. Έτσι δεν φεύγει κατά λάθος email σε πραγματικό συνεργάτη.

Το `make run` είναι το ίδιο με `python main.py`. Όλες οι εντολές φαίνονται με
`python main.py --help`, αφού ενεργοποιηθεί το περιβάλλον με `source
.venv/bin/activate`.

## Τι υπάρχει στον φάκελο

| Φάκελος ή αρχείο | Τι είναι |
|---|---|
| `main.py` | Από εδώ ξεκινά ο agent |
| `agent/` | Ο κώδικας· κάθε αρχείο έχει στην αρχή του μια γραμμή που λέει τι κάνει |
| `tests/` | Οι αυτόματοι έλεγχοι |
| `docs/` | Οι προδιαγραφές της ομάδας |
| `Makefile` | Οι συντομεύσεις `make install`, `make run`, `make test` |
| `requirements.txt` | Οι βιβλιοθήκες που χρειάζεται |
| `.env.example` | Υπόδειγμα ρυθμίσεων |

Η βάση (`data/`), τα αρχεία του μήνα (`input/`), το `.env` με τους κωδικούς και
κάθε αρχείο Excel μένουν στον υπολογιστή σας και δεν ανεβαίνουν στο git.

## Τι δεν έχει γίνει ακόμη

- Το αρχείο του μήνα το βάζει κάποιος με το χέρι· δεν το παίρνει ο agent από το
  σύστημα που το βγάζει.
- Τρέχει όσο είναι ανοιχτό το `make run`. Για καθημερινή αυτόματη λειτουργία
  χρειάζεται υπολογιστή που μένει ανοιχτός.
- Το dashboard δεν έχει σύνδεση χρηστών, γι' αυτό ανοίγει μόνο από τον ίδιο
  υπολογιστή.
- Η ανάγνωση με AI έχει δοκιμαστεί μόνο με απαντήσεις που γράψαμε εμείς.
